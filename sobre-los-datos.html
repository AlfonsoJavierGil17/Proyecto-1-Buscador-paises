Origen y Atribución de los Datos

Todos los datos geográficos y demográficos mostrados en este sitio web han sido obtenidos directamente de la API pública libre REST Countries.

  • Mantenedor: Proyecto de código abierto alojado en GitHub.
  • Documentación oficial:
  • Peticiones utilizadas: GET https://restcountries.com/v5
  • Licencia: Open Data

Transformación: De JSON a HTML Semántico

A continuación se muestra un ejemplo real de cómo el objeto recibido en formato JSON se transforma en elementos HTML5 dentro del sitio web:

Fragmento de origen (JSON):

{ "name": { "common": "Italia", "official": "República Italiana" }, "capital": [ "name": "Rome" ], "flag":{ "url_png": ""https://flags.restcountries.com/v5/w640/it.png"" } "region": "Europe", "population": 125_800_000 }

Resultado marcado en la web (HTML):

Italia

capital: Roma

poblacion de 125 millones de personas
